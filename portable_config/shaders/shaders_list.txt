Shader sources, for rebuilding this folder on a fresh install.
Grouped by upstream repo. Folder paths are relative to portable_config/shaders/.

== Anime4K/ ==
Used by: input.conf CTRL+1-6, CTRL+!-&, uosc Video > Shaders > Anime4K
Source: https://github.com/bloc97/Anime4K
Grab the GLSL release (currently v4.0.1) from the Releases page, "GLSL" asset.
Every Anime4K_*.glsl file in this repo's release goes into Anime4K/.

== ArtCNN/ ==
NOT currently used (CTRL+8 / CTRL+SHIFT+8 were removed, too heavy on this GPU).
Source of ArtCNN_C4F32_DS.glsl: https://github.com/Artoriuz/ArtCNN, GLSL/ArtCNN_C4F32_DS.glsl
ArtCNN_C4F64_DS.glsl has NO verified upstream source, it is not in the official
ArtCNN repo. Left over from an earlier session, candidate for deletion along
with the rest of this now-unused folder.

== RAVU/ ==
Not wired to a keybind right now, kept as a fresher alternative to the legacy
ravu_L_ar_r4.hook / ravu_Z_ar_r3.hook below.
Source: https://github.com/bjin/mpv-prescalers, gather/ folder (fastest variant set)
Files here: ravu-lite-ar-r2/r3/r4.hook, ravu-r2/r3/r4.hook, ravu-3x-r2/r3/r4.hook,
ravu-zoom-ar-r2/r3.hook

== hdr-toys/ ==
Not wired to anything yet, pending a check of the monitor's real HDR spec.
Source: https://github.com/natural-harmonia-gropius/hdr-toys

== Retro/, original 7 (CRT and stylize) ==
crt-lottes.glsl, crt-hyllian.glsl, crt-gizmo.glsl, crt-aperture-dsaa.glsl,
crt-royale-fb.glsl, technicolor.glsl, dither.glsl
Source not tracked, these were already in this config before the source-audit
session, no matching upstream repo confirmed. Treat as vendored as-is.
